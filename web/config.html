UFW 同步 — 配置

可信白名单对来源全放行（host + docker）。此处只改配置；执行（Dry-run / 应用）在「UFW 同步」页。空可信白名单在应用时会被跳过（fail-safe，绝不锁死）。

可信白名单

家庭 DDNS (IPv4)
各节点本地解析为 A 记录后放行
家庭 DDNS (IPv6)
解析后掩为 /64 放行
静态白名单 (IPv4 / CIDR)
固定放行的地址或网段
静态白名单 (IPv6 / CIDR)
固定放行的地址或网段

调度与开关

开启后，每次应用会探测 tailscaled 当前监听的（随机）UDP 端口并放行（标签 komari-ufw-ts），端口漂移时下次同步自动更新；关闭则清除该标签规则。仅在 apply 生效。
